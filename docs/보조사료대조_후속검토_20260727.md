## A. 민회↔민단 귀속 — **해소 (조치 불요)**

초판에서 "민단사는 민회 의원으로 기재, 본 데이터는 대구거류민단 레코드"를 문제로 제기했으나, 이는 **잘못된 문제 제기였다.**

- 대구거류민단(O003)의 의결기관이 거류민회(민회)이며, 별개 조직이 아니다(저자 확인 2026-07-27).
- 조직레지스트리 O003 비고에 이미 판정례 R-01로 "민단기 의결기관 '거류민회(민회)'는 본 레코드에 포함"이 명시되어 있고, O003에 민회의원 레코드 23건이 이미 귀속되어 있다.
- O002 대구일본인거류민회(1904-08~1906-11)는 민단에 선행한 별개 조직으로, 현행 구분이 맞다.

**→ 데이터 변경 없음.** 코딩북 §6에 귀속 원칙을 명문화하고 J-19를 추가하였다.
