**버전**: v1.8 (2026-08-09) — 직무분류 11범주 신설(§3.5·R-13), 직위 통제어휘 17종→14종(회두·부회두·회원 삭제), OH0875 삭제(J-26), 직무분류 판정 반영(J-27)

## 0. 총칙

1. **근거 없는 레코드 금지**: 모든 레코드에 근거 절 ID를 기재한다. 보조 사료 근거는 "문헌명 p.페이지" 형식으로 병기한다.
2. **근거 단위 = 절 (v1.1 개정)**: 정본은 `대구물어본문.txt`이며, 인용 단위는 『대구물어』의 절(節)이다. 절 구분은 **장·절 목차의 정본인 `대구물어_장_절_목차_p제외.xlsx`**를 본문 표제 행과 대조하여 확정한 `절구분_v4_20260728.csv`(**349절 + 장 서두 6 = 355단위**; 82장은 목차 정본에 따라 '하사금을 받다·이토 태자태부·여단장 교체·민단, 위기로 무너지다'의 4절 — J-25, J-16 폐기)를 따른다. 절 ID는 `장번호-절순번`(예: `24-3` = 제24장 3절 '쇄신회의 활약'), 장 제목과 첫 절 사이의 본문은 `장번호-0`(장 서두)으로 표기한다. 범위 인용은 `55-1~55-3` 형식. 논문 본문 인용 형식은 "『대구물어』 제24장 3절"로 한다.
   - 구 단락 체계(P0000~P1403)는 기존 v3.3 데이터(`단락별_인물출현_v3.json`, `언급레코드_v3.json`, `단락_시기매핑.csv`, `장_구분.json`)에만 남는다. 이들은 **탐색 인덱스로만** 사용하며, 신규 레코드의 근거 표기에는 사용하지 않는다.
3. **인물 ID**: `인물명단_통합_v3.csv`의 대표 표기를 그대로 사용한다(ID 불변, 신규 인물 발견 시 별도 목록으로 관리하고 임의 추가하지 않는다).
4. **공출현 불사용**: 두 인물이 같은 절에 등장한다는 사실만으로는 어떤 레코드도 만들지 않는다. 공출현·중심성·커뮤니티 산출물은 수집 순서 결정과 점검표로만 쓴다.
5. **탐색과 증거의 분리**: LLM 보조·자동 감지로 찾은 후보라도, 레코드 확정은 근거 절 원문의 명시적 서술로만 한다.

## 1. 조직 레지스트리 판정 규칙

### 1.1 등재 기준
- 등재한다: 본문에 **명칭이 있는** 지속적 결사·기관·회사 — 행정기구(민회·민단), 경제 단체(상업회의소)·회사(은행·전기·신문사 등 법인), 언론(신문·잡지), 교육·종교(학교·학교조합·신사·사원), 동향·친목 단체(팔조회 등), 위생·소방 등 공익 조합, 임시조직(위원회·기성회·후원회 — 단, 반복 언급되거나 임원 구조가 있는 것).
- 등재하지 않는다: 개인 상점·상호(조직적 실체 서술이 없는 경우), 관청 그 자체(통감부·관찰부 등 국가기구 — 단, 인물의 직위 맥락으로는 소속직위표에 기록 가능하도록 `기관(관청)` 유형으로 별도 표기 가능), 지명·시설물.
- 경계 사례: 조직적 활동(회합·임원·회칙·모금)이 서술된 상점·조합은 등재. "OO파(派)" 같은 비공식 파벌은 등재하지 않되 비고에 메모.

### 1.2 구분 원칙 (별개 레코드 + 관계 연결)
| 사례 | 처리 |
|---|---|
| 민회 ↔ 민단 | 별개 레코드, `전신/후신` 필드로 승계 연결 |
| 신문 제호 ↔ 발행 회사 | 별개 레코드(예: 신문 '대구일일신문' ↔ 그 경영 회사), `소속관계`로 연결 |
| 본점 ↔ 지점 | 별개 레코드(지점의 독자 활동이 서술될 때만 지점 등재) |
| 후원회 ↔ 정식 조직 | 별개 레코드 |
| 개편·개칭 | 동일 실체의 개칭은 한 레코드에 이명으로, 해산 후 재설립은 별개 레코드 |

### 1.3 필드 정의
`org_id`(O001~) / `표준조직명` / `한자표기` / `이명·전신·후신` / `조직유형`(행정·자치 / 경제 / 언론 / 교육·종교 / 동향·친목 / 위생·소방·공익 / 임시조직) / `설립시기`·`개편시기`·`해산시기`(연 또는 연월, 불확실 시 구간 "1906~1907", 불명 시 공란) / `근거절` / `보조출전` / `근거수준`(보조사료 대조 확인 / 대구물어 단독 전거) / `비고`

## 2. 사건 레지스트리 판정 규칙

### 2.1 등재 기준
- 등재한다: 시기를 특정(최소 연 단위 추정)할 수 있고 참여자가 식별되는 집합적 사건 — 조직 설립·개편·해산, 선거·임명, 창간·경영권 이전, 집단운동·대회·집회, 중재·교섭, 청원·진정, 의례(축하회·추도회·환영회), 재난·사고(집합적 대응이 서술된 것).
- 등재하지 않는다: 개인 간 일화(사적 다툼·거래 등 집합적 성격이 없는 것), 시대 상황의 일반 서술, 저자의 논평.
- 경계 사례: 개인 일화라도 조직·공론이 개입하면(예: 중재에 유력자들이 나선 분쟁) 등재.

### 2.2 위계
- 지속적 캠페인(예: 이용익 배척운동)은 상위 사건 1건 + 개별 국면(집회·결의·대표 파견)을 하위 사건으로. `상위사건` 필드로 연결.
- 정례 행사(매년 선거)는 회차별 별개 사건.

### 2.3 필드 정의
`event_id`(E001~) / `사건명`(간결 요약형, "OO 설립", "제N회 OO 선거" 형식 권장) / `사건유형`(설립 / 선거·임명 / 조직개편 / 창간·경영이전 / 집단운동·대회 / 중재·교섭 / 청원 / 의례 / 재난·사고 / 회의·결의 — R-09) / `시기`(연 또는 연월~연월; **임의 날짜 부여 금지**) / `시기근거`(본문서술 / 보조사료 / 시기매핑추정) / `관련조직`(org_id 목록) / `상위사건`(event_id) / `근거절`(범위 허용 55-1~55-3) / `보조출전` / `근거수준` / `비고` / `참여자메모`(단계 4 참여표 작성 재료) / `지역구분`(대구 / 경북관내 / 전국-대구반응 — R-11) / `시기구분`(시기내 / 시기외) / `관련조직_미매핑`(레지스트리 미등재 조직명 텍스트)

### 2.4 시기 판정 우선순위
① 본문의 명시적 연월 서술 → ② 보조 사료(민단사 연표 등) → ③ 장별 대표연도(`단락_시기매핑.csv`)는 **후보로만**, `시기근거=시기매핑추정`으로 표기. ①②가 충돌하면 보조 사료(관찬) 우선하되 비고에 양쪽 기록.
- **단서(v1.1, R-05)**: 회고록이 구체 일자를, 관찬이 월 단위만 제시하고 양자가 같은 달 또는 인접 월이면 회고록 일자를 채택하되 비고에 관찬 표기를 병기한다.

## 3. 소속·직위표 판정 규칙

### 3.1 직위 통제어휘
회장 / 부회장 / 회장대리 / 의장 / 평의원·의원 / 이사·간사 / 조합장 / 단장 / 사장 / 주필 / 기자 / 지배인 / 발기인 / 기타(원어를 원표기에 보존) — **14종 (v1.8 개정)**
- 삭제 어휘(v1.8): `회두`·`부회두`(실레코드 0건 — 회의소 장은 전부 '회장'으로 판정됨), `회원`(실레코드 0건 — 직함 없는 구성원은 어휘가 아니라 `구분=소속`으로 기록한다는 운용을 명문화)
- 본문 표기가 통제어휘와 다르면: 원어를 `원표기` 필드에 보존하고 가장 가까운 통제어휘로 매핑. 매핑이 애매하면 `기타` + 원표기.
- "임원"의 정의: 명칭 있는 직책 일체(회장~지배인, 발기인 포함). 직함 없는 구성원·단순 참가는 임원이 아니며 `구분=소속`으로 기록한다(v1.8 명문화 — 실데이터의 기존 운용과 동일: 소속 176건에 원표기 '회원' 등 보존).

### 3.2 인정 기준
- **명단형 절의 명부**: 직위 명시 명부("평의원 당선자는 다음과 같다…")는 열거 전원을 해당 직위로 등재 — 직접 증거.
- **서사형 절의 명시 서술**: "오구라가 회두가 되어…" 식 서술도 직접 증거.
- 인정하지 않음: 정황 추정("민회 일에 자주 관여했다"), 공출현.
- 발기인: 조직 설립의 발기인은 소속직위표(직위=발기인)와 사건참여표(설립 사건, 역할=발기인) **양쪽에 기록**한다(관점이 다른 두 표이므로 중복이 아님).

### 3.3 시간 구간
취임·재임 연도를 알 수 있는 범위로(연 단위). 선거 명부는 해당 회기로. 불명은 공란.

### 3.4 필드 정의
`record_id`(OH0001~) / `인물` / `조직(org_id)` / `구분`(직위 / 소속) / `직위(통제어휘)` / `원표기` / `시간구간` / `근거절` / `보조출전` / `근거수준` / `보조사료대조`(v1.4 신설) / `교차확인비고`(v1.4 신설) / `비고` / `직무분류`(v1.8 신설 — §3.5)

### 3.5 직무분류 (v1.8 신설)

**목적**: 직위 통제어휘가 '기타'로 남기던 관직·위원직 등(465건, 47.7%)을 기능 축에서 포괄 분류한다(논문 한계 ⑧ 해소).

**부여 범위**: `구분=직위` 레코드 전체(관내·관외 불문)에 부여한다. `구분=소속` 레코드에는 부여하지 않는다(공란 — 구성원임은 구분 필드가 표시).

**축 원칙**: 직무분류는 직무(기능) 축만 판정한다. **임명 주체는 어느 필드에서도 판정하지 않는다**(회고록이 명시하는 것은 소속 기관이지 임명 주체가 아님). 기관 구분(한국 관청/통감부·이사청/일본 본국/임시조직 등)은 조직레지스트리에서 파생하는 `기관계열` 필드(후속 예정)로만 다루고, 임시/상설 구분도 조직 축(조직유형=임시조직)이 표현한다.

**투영표(어휘 → 직무분류)** — 결정적(1:1) 매핑이며, 예외는 레코드 단위 판정례로만 허용한다(현재 1건: J-27의 '의병 대장').

### 3.6 기관계열 (v1.8 신설 — 파생 필드)

**정의**: 레코드가 속한 조직·기관의 계열. **판정 필드가 아니라 파생 필드**다 — 매핑 레코드(790건)는 조직레지스트리의 `조직유형`을 그대로 복사하고, 미매핑 레코드(183건)는 비고에 보존된 기관명으로 부여한다.

**미매핑 전용 어휘(7종)**: 관외:한국 관청(74) / 관외:기업·언론(43) / 관외:일본 본국(35) / 관외:일본군(20) / 관외:결사·자치(5) / 관외:영사관(1) / 불명(5)

- `불명`은 비고에 소속 기관 자체가 기재되지 않은 경우(성만 표기 등 5건: OH0797·OH0847·OH0886·OH0915·OH0968)로, 총칙 ④와 같은 원칙으로 불명으로 남긴다(임의 부여 금지).
- 임명 주체 판정 금지 원칙(§3.5)은 여기에도 적용된다: 기관계열은 소속 기관의 명칭 기반 분류이며, 한국정부/통감부 임명 여부를 판정하지 않는다.

## 4. 사건 참여표 판정 규칙

### 4.1 역할 통제어휘
발기인 / 주도자 / 연설자 / 대표·위원 / 중재자 / 당사자·대상 / 참석자
- **발기인**: 발기인 명단에 이름이 있는 자. **주도자**: 서술상 사건을 조직·지휘한 자(발기인 명단이 없어도). **연설자**: 등단·연설이 명시된 자. **대표·위원**: 대표로 선출·파견된 자. **중재자**: 분쟁·교섭에서 제3자로 개입한 자. **당사자·대상**: 사건이 겨냥하거나 상대한 자(배척의 대상, 교섭의 상대방, 피해자) — 조선인 등장 양상 포착의 핵심 범주. **참석자**: 참석 사실만 확인되는 자.
- 한 인물이 한 사건에서 복수 역할이면 역할별 레코드 분리.

### 4.2 "참석"과 "참여"의 구분
- 명부·서술로 **개인이 식별**될 때만 레코드 생성. "수백 명이 모였다"는 사건 레지스트리의 비고에만 기록.
- 열거 명단이 사건 부속 명단(발기인·당선자·위원)이면 전원 등재. 단순 언급 동반자는 서술상 행위가 확인될 때만.

### 4.3 필드 정의
`record_id`(EP0001~) / `인물` / `사건(event_id)` / `역할(통제어휘)` / `원표기` / `근거절` / `보조출전` / `근거수준` / `비고`

## 5. 명단형 절의 이분 규칙 (소속 vs 참여)

| 명단의 성격 | 처리 |
|---|---|
| 상설 조직의 임원 명부·회원 명부 | 소속직위표 |
| 특정 사건 부속 명단(발기인·당선자) | 사건참여표 (+ 당선자는 소속직위표에도 — 당선으로 직위가 생기므로) |
| 판별 곤란 | 코딩북에 사례 추가 후 판정 |

같은 절이 양쪽 표의 근거가 될 수 있다(예: 평의원 당선자 명단 = 선거 사건의 참여 + 평의원 직위의 개시). 이는 중복 판독이 아니라 두 표의 정의 차이다.

## 6. 근거수준 부여 규칙

**대전제 (v1.4)**: 본 연구의 1차 근거는 『대구물어』이며, 『대구민단사』 이하 보조 사료는 참조 자료다. 보조 사료에서 확인되지 않는다는 사실은 레코드의 결함이 아니다. 근거수준 필드는 레코드의 우열이 아니라 전거의 종류를 표시한다.

`근거수준` (2치)

- `보조사료 대조 확인`: 보조 사료에서 같은 사실(같은 인물·직위·조직 또는 같은 사건·연대)이 확인됨. `보조출전` 필수.
- `대구물어 단독 전거`: 『대구물어』 서술만이 전거인 경우. 보조 사료에 기재가 없는 경우와 대조를 하지 않은 경우를 모두 포함한다.

`보조사료대조` (3치, v1.4 신설 — 위 2치가 뭉뚱그리는 두 상태를 분리하기 위함)

- `확인`: 보조 사료에서 확인됨.
- `미확인`: 보조 사료를 대조했으나 해당 기재가 없음. **반증이 아니다** — 레코드는 그대로 유지한다.
- `미대조`: 아직 대조 대상이 아니었음.

판정 규칙

- 보조 사료가 같은 인물에 대해 **다른** 직위·시기를 전하는 경우는 `미확인`이 아니라 **불일치**로 처리하고, 비고에 상술한 뒤 코딩북 판정례로 올린다(2026-07-27 218건 대조에서 불일치 0건).
- 표기가 달라도 한자 표기·직무 연속성으로 동일 대상임이 판정되면 `확인`으로 하고 표기 차이를 비고에 남긴다(J-18).
- 보조출전은 문헌명까지만 기재하고 페이지는 요구하지 않는다(2026-07-24 저자 지시).
- 대조 판정 단위는 **인물×조직×직위 레코드**다. 같은 인물이 보조 사료에 다른 직위로 나오는 것은 해당 레코드의 확인 근거가 되지 않는다(J-19).
- 민단기(1906-11~)의 의결기관 '거류민회(민회)'는 별개 조직이 아니라 대구거류민단(O003)의 기관이므로, 민회의원 레코드는 O003에 귀속한다(R-01 재확인, 저자 확인 2026-07-27). 이와 구별되는 O002 대구일본인거류민회는 1904-08~1906-11의 선행 조직이다.
- 본문 핵심 주장은 전거 종류와 무관하게 근거 절로 지지되면 사용하되, 단독 전거에 근거한 주장은 그 사실을 명시한다.

## 5-2. 사건 참여 등재 제외 규칙 (v1.6 신설)

명부에 이름이 있더라도 **사건에 대한 행위로 볼 수 없는 기재**는 참여 레코드로 만들지 않는다. 역할 통제어휘 7종은 모두 행위를 가리키므로, 어디에도 배정할 수 없는 기재는 등재 대상이 아니다.

- 제외: 추첨·경품 당첨자 명단, 수혜 대상 명부 등 결과로서 이름이 오른 경우(J-24).
- 유지: 사건의 대상이 된 자는 `당사자·대상`으로 등재한다. '겨냥된 것'과 '결과로 이름이 오른 것'은 다르다.
- 민족·집단 간 비교에 쓰이는 표에서는 **제외를 한쪽에만 적용하지 않는다**(J-24에서 조선인 4건과 일본인 4건을 함께 제외).
- 역할 재판정 시에는 **같은 사건 안에서 같은 성격의 기여가 같은 역할을 받도록** 맞춘다(J-23).

## 6-2. 도래 연도 판정 규칙 (v1.5 신설)

**원칙: 도래 연도는 대구 도래를 기준으로 한다.** 조선(한국) 도래와 대구 도래는 별개의 사실이며, 거류지 공공 영역에서의 고참 여부를 가르는 것은 후자다. 『대구물어』 자신이 두 가지를 구별해 서술한다(39-2).

- `도래연도_대구`: 대구에 정착한 연도(연 또는 연월). 판정의 기준 필드.
- `도래연도_조선`: 조선의 다른 지역에 먼저 체류한 경우 별도 기입. 대구 도래 판정에 사용하지 않는다.
- 두 값이 다른 사례: 미와 조테쓰(조선 1891 잠업교사 → 대구 1903 매약), 이즈카 쇼이치(조선은 1893 이전 → 대구 1903경), 사카모토 도시스케(부산 1897경 → 대구 연도 불명).
- **활동 연도를 도래 연도로 대용하지 않는다.** 활동연도범위의 하한은 최초 등장 기록일 뿐이다(J-21).
- 근거 우선순위: 『대구물어』 본문 서술 > 보조 사료. 보조 사료가 구간으로만 전하고 본문이 특정 시점을 전하면 본문을 취한다(예: 시부사와 슈조 — 민단사 "1904~05" vs 본문 96-2 "1904년 1월경" → 후자).
- 기준 절: 11-1(히자쓰키 마스키치 1893-09, 대구 최초 일본인 이주자), 39-2(팔조회 고참 순 서술), 96-2(오구라·후지나와·시부사와 1904-01경).

## 7. 판정례 (누적)

- **R-00(예시)** 오키타 스테지로 — "대구일일신문의 사장이었다"는 서사형 명시 서술 → 소속직위표(조직: 대구일일신문, 직위: 사장, 근거절 기재). 신문 제호와 경영 회사가 본문에서 구분되면 별개 레코드로.
- **R-01** 민단법 실시(1906-11) 이후의 "거류민회(민회)"는 민단의 의결기관이므로 별도 레코드로 만들지 않고 대구거류민단 레코드에 포함한다. 1904~06의 자치단체 거류민회와는 구별(별개 레코드 + 전신/후신 연결).
- **R-02** 개칭 연쇄 신문(대구실업신문→대구신보→대구일일신문)은 동일 실체 1개 레코드(이명 기재). 합병으로 신설된 대구신문과 미발행 신설사 대구신보사(1908)는 각각 별개 레코드로 하고 전신 관계로 연결(1.2 적용례).
- **R-03** 제호(대구신문)와 경영체(대구신문사조합)는 본문에서 구분 서술되므로 별개 레코드(1.2 신문 규칙 적용례).
- **R-04** '개혁파'류 무정형 파벌(회칙·맹주 없음이 본문에 명시)은 등재하지 않고 관련 조직 비고에 기록(1.1 적용례). 단 공민회(발기인·발회식 있음)는 정치결사로 등재.
- **R-06(지역 범위)** 등재 범위는 ①대구 소재 조직 ②대구를 직할하는 기관(부산영사관·통감부) ③경북 관내 소재·활동 조직(관내 일본인회, 경산 소재 회사 등)로 한다. 관내 관할 활동이 서술된 인접 도 기관(부산이사청)도 포함. 그 외 외지(경성·부산·일본) 조직은 제외하고 제외메모에 보존(저자 판정 2026-07-22).
- **R-07(분석시기 외 결성)** 본문에 서술된 조직이 분석시기(1903~1910) 밖에 결성된 경우(팔조회 1913, 갑진회 1928 등) 등재하되 비고에 표시하고, 시기별 분석 집계에서는 제외한다(저자 판정 2026-07-22).
- **R-08(경계 사례 확정)** 도미시마구미(조직 구조 서술)·니시키좌(공공 오락장 기능)·대구권상장(무진계 공동 출자)은 등재. 맥주회·가미야상회 구락부·대구보세창고는 미등재 유지(저자 판정 2026-07-22).
