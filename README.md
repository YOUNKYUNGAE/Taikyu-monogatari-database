# 재현 패키지 — 『대구물어』 인물·조직·사건 데이터베이스

**논문**: 「『대구물어』의 인물·조직·사건 데이터베이스 구축과 이원 연결망 분석 — 러일전쟁~병합기 대구 일본인 사회의 프로소포그래피」
**작성일**: 최종 공개판 2026-08-12 (초판 2026-07-27)
**저장소 URL**: 

이 패키지는 논문의 모든 수치와 그림을 원 데이터에서 다시 산출할 수 있도록 구성되었다. 별도 라이브러리 설치 없이 검증을 재현할 수 있고, 그림 재현에는 matplotlib과 한글 지원 폰트만 필요하다.

---

## 빠른 시작

```bash
python3 scripts/verify.py            # 기계 검증 + 논문 표 수치 재산출 (표준 라이브러리만)
python3 scripts/make_aggregates.py   # 겸직 지표·영역 행렬 재산출 (표준 라이브러리만)
python3 scripts/permutation_test.py  # 표 7 순열검정·7장 Fisher 정확검정 재산출 (표준 라이브러리만)
python3 scripts/make_figs_v5.py      # 그림 1~5 재생성 (matplotlib, Noto Sans CJK JP)
python3 scripts/make_fig3_networks.py # 그림 3-1·3-2 이원 연결망 재생성 (networkx·adjustText·graphviz 추가 필요)
```

`verify.py`는 모든 항목이 통과하면 종료 코드 0, 하나라도 실패하면 1을 반환한다.

### 주요 필드

**근거절** — 모든 레코드의 필수 필드. `장번호-절순번` 형식(`24-3` = 제24장 3절). 범위는 `55-1~55-3`, 복수는 세미콜론. `절구분_v4_20260728.csv`로 유효성을 검증할 수 있다.

**근거수준** — `보조사료 대조 확인`(127) / `대구물어 단독 전거`(846)의 2치.

**보조사료대조** — `확인`(127) / `미확인`(91) / `미대조`(755). '미확인'은 보조 사료를 대조했으나 기재가 없는 경우이고 '미대조'는 대조하지 않은 경우다. **미확인은 반증이 아니며 레코드는 그대로 유효하다**(코딩북 §6).

**org_id 공란** — 소속·직위 레코드 183건은 대구·경북 관내 밖 조직(한국 정부 부처, 부산 조직, 군 부대 등)에 대한 것으로, 조직 레지스트리에 매핑하지 않고 비고에 조직명을 남겼다. 겸직 지표와 이원 연결망은 매핑된 790건 위에서 산출된다(논문 3.1절).

## 알아 둘 점

**1. 사건 위계는 부록 연표를 함께 봐야 완결된다.** 전국 배경 사건 32건을 부록으로 분리할 때 `event_id`와 상호 참조를 유지했다(판정례 R-11/J-12). 그래서 본 레지스트리의 E175·E183·E184는 부록 연표에 있는 상위 사건(E174·E182·E173)을 참조한다. `verify.py`는 두 파일의 합집합으로 참조 무결성을 검사한다.

**2. 『대구물어』 본문 텍스트는 포함하지 않는다.** 저작권 보호 대상이기 때문이다. `절구분_v4_20260728.csv`의 절 ID와 시작·끝 행 번호로 소장본과 대조할 수 있다.

**3. 공출현·중심성·커뮤니티 지표는 포함하지 않는다.** 선행 연구의 산출물이며 본 연구에서는 후보 탐색에만 쓰고 실증 근거로 인용하지 않았다(탐색과 증거의 분리 원칙).

**4. 인물 레지스트리는 동결 승계분이다.** 선행 연구에서 구축한 642건을 ID 불변으로 승계했고 본 연구에서 수정하지 않았다.

**5. 사건 참여표는 복권 제외·숙소 재판정 반영본이다.** 달성공원기성회 복권 추첨 당첨자 명단 8건(조선인 4·일본인 4)은 사건에 대한 행위로 볼 수 없어 제외했고(J-24), 순종 남순행 봉영 위원회에서 귀빈 숙소를 분담한 조선인 7명은 같은 사건의 일본인 위원과 동일하게 `대표·위원`으로 재판정했다(J-23). 1,261 → 1,253건, 전체 등장 인물 599 → 591명. **`집계_조선인비대칭_v1.json`은 현재 데이터로 재현되지 않아 폐기하고 v2를 산출했으며, 최종 공개판에서는 J-26(레코드 1건 삭제)을 반영한 v3으로 갱신했다.**

**6. 활동 영역 배정 규칙은 `scripts/make_aggregates.py`에 구현되어 있다.** 행정·경제·언론은 소속 조직의 유형으로, 동원은 '집단운동·대회'·'청원' 사건의 발기인·주도자·연설자·대표위원 역할로 정한다(논문 3.7절).

**7. 수정판 변경 사항(2026-07-27).** 논문 6.3절의 영역 겹침 지표를 교체했다. 종전의 전체 591명 기준 독립 기댓값 배수는 영역 미보유 431명이 분모에 들어가 모든 쌍의 배수를 일률적으로 부풀리는 문제가 있어, 인물별 영역 수와 영역 규모를 보존한 순열검정(`scripts/permutation_test.py`)으로 대체했다. 이에 따라 구버전 집계 파일(`집계_겸직지표_v1.csv`, `집계_영역행렬_v1.json`)을 패키지에서 제거하고, `집계결과_요약_20260727.txt`의 구 수치(599명·조선인 48/974 등)를 v2 기준으로 정정했으며, `verify.py`의 표 5 검사 항목을 관측 겹침·겸직 집중도·Fisher 검정으로 갱신했다. 그림 5에 검정 결과를 병기했다(`make_figs_v5.py`).

**8. 최종 공개판 변경 사항(2026-08-12).** 데이터 정본을 `사건레지스트리_v3_20260728`(근거절 재부여, J-25)·`사건참여표_v3_20260728`(동일)·`소속직위표_v6_20260809`(직무분류 11범주·기관계열 필드 신설, '수령' 레코드 1건 삭제로 974→973건 — J-26·J-27)·`절구분_v4_20260728`(82장 4절 복원, 355단위)로 교체하고, 코딩북을 v1.8로 갱신했다. 스크립트의 입력 경로를 이 정본들로 통일하고, 겸직 지표·영역 행렬을 재산출했으며(`집계_겸직지표_v4_20260812.csv`, `집계_영역행렬_v4_20260812.json`), `집계_조선인비대칭_v3_20260812.json`에 소속·직위표 973건·조선인 76건(7.8%)을 반영했다. `verify.py`의 기대값을 최종 수치로 갱신했고 전 항목이 통과한다. 그림 3을 인물–조직(3-1)·인물–사건(3-2) 이원 연결망 두 장으로 분리해 추가하고(`make_fig3_networks.py`), 그림 4는 전 타일 숫자 표기로, 그림 5는 주석·라벨·강조색을 정비했다. 스크립트가 출력하는 표 번호는 최종 논문의 표 번호(표 1 데이터셋 규모, 표 4 보조 사료 대조, 표 6 핵심 중첩층, 표 7 영역 쌍, 표 8 시기별 임원, 표 9 민족별 역할)를 따른다.
